Tool Integration Guide

Ready-to-use snippets to authenticate your preferred runtime or CI/CD platform.

1. Docker CLI

echo "<YOUR_API_KEY>" | docker login  -u admin --password-stdin

2. Tag & Push an Image

docker tag my-app:latest /my-app:latest
docker push /my-app:latest

3. Podman CLI

podman login  -u admin --password "<YOUR_API_KEY>"

4. Kubernetes Secret

kubectl create secret docker-registry zot-regcred \
  --docker-server= \
  --docker-username=admin \
  --docker-password="<YOUR_API_KEY>"

5. GitHub Actions Workflow

- name: Login to Private Registry
  uses: docker/login-action@v3
  with:
    registry: 
    username: admin
    password: {% raw %}${{ secrets.REGISTRY_API_KEY }}{% endraw %}
