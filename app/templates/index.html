Multi-Platform Code Generator

Ready-to-use snippets to authenticate and push/pull from any container engine or CI/CD platform.

Authenticate & Push 
# 1. Login with API key
echo "<YOUR_API_KEY>" | docker login  -u admin --password-stdin

# 2. Tag image
docker tag my-app:latest /my-app:latest

# 3. Push image
docker push /my-app:latest
Podman Login & Push 
podman login  -u admin --password "<YOUR_API_KEY>"
podman tag my-app:latest /my-app:latest
podman push /my-app:latest
Kubernetes imagePullSecrets 
# Create secret
kubectl create secret docker-registry zot-regcred \
  --docker-server= \
  --docker-username=admin \
  --docker-password="<YOUR_API_KEY>"

# Reference in pod manifest:
spec:
  imagePullSecrets:
    - name: zot-regcred
  containers:
    - name: app
      image: /my-app:latest
Push Helm Chart as OCI Artifact 
# 1. Login Helm to Zot OCI
helm registry login  -u admin --password "<YOUR_API_KEY>"

# 2. Package & Push Helm Chart
helm package ./my-chart
helm push my-chart-0.1.0.tgz oci:///charts
